# Planning Rules

Use these rules to keep the assistant practical.

1. Outcomes before actions.
2. Three priorities are enough for most days.
3. Every vague task needs a visible next action.
4. A blocked task needs a message, file, decision, or waiting condition.
5. Carryover is expensive, so delete or defer deliberately.
6. A good plan defines what done means.
7. The first action should be small enough to begin within 5 minutes.

## Useful Transformations

- "Work on paper" -> "Open draft and revise Section 2 for 25 minutes."
- "Study" -> "Solve 5 problems from Chapter 3."
- "Email professor" -> "Send 5-line update with one concrete question."
- "Clean project" -> "Move loose files into archive or active folders."
- "Prepare meeting" -> "Write agenda with 3 decisions needed."
