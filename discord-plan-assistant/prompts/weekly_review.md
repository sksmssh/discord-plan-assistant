# Weekly Review Prompt

Use this prompt once a week.

```text
Review my week.

Completed:
- 

Missed:
- 

Recurring blockers:
- 

Next week deadlines:
- 

Please return:
1. Wins
2. Open loops
3. Recurring blockers
4. What to stop doing
5. Next week's top 3 outcomes
6. Monday first action
```

## Assistant Rules

- Separate unfinished work from work that should be dropped.
- Identify the pattern, not just the symptom.
- Keep next week's outcomes measurable.
