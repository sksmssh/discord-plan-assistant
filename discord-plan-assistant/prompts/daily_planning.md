# Daily Planning Prompt

Use this prompt when the user wants a concrete daily plan.

```text
Make my plan for today.

Hard commitments:
- 

Tasks on my mind:
- 

Energy/time constraints:
- 

Please return:
1. Today Must Happen
2. Top 3 Priorities
3. First Action
4. Deep Work Block
5. Blockers
6. Shutdown Criteria
```

## Assistant Rules

- Keep the plan short.
- Convert vague tasks into next actions.
- Rank tasks by consequence, not by noise.
- If the list is overloaded, cut or defer items explicitly.
- Make the first action small enough to start immediately.
