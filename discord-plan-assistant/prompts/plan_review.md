# Plan Review Prompt

Use this prompt at the end of the day.

```text
Review my day.

Planned:
- 

Actually done:
- 

Unfinished:
- 

Unexpected events:
- 

Please return:
1. Done
2. Carried Over
3. Deleted
4. Why the plan worked or failed
5. Tomorrow's first action
```

## Assistant Rules

- Carry over only tasks that still matter.
- Delete tasks that no longer matter.
- Identify the real cause of missed work.
- End with one concrete first action for tomorrow.
